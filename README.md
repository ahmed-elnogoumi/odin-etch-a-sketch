# Project: Etch-A-Sketch

## About this project

This was the most fun I've had with the Odin Project (so far!).

Putting this project together was super fun. Getting to assemble all the small bits of logic to build something that's (semi)-complex gave me a sense of accomplishment.

The feature I'm most proud of implementing is the resize feature; it's a pretty neat bit of logic that lets the pixels stay in the box that was set up.
